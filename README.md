## 年付 vs 月付：DMIT 东京的折扣门槛在哪里

DMIT 这家商家的促销节奏在圈内算克制的一类，活动频率低，优惠码数量少。它的折扣码普遍带两重限制：绑定产品线，绑定付款周期。

以日本 Tier 1 系列为例，公开流传的 `2025-TYO-T1-HI-GSL-NON-MONTHLY-30OFF` 覆盖 TYO.T1.TINY 及以上套餐，但只有在季付或更长周期才生效，力度是七折并循环。同样这条产品线的月付码 `2025-TYO-T1-HI-GSL-MONTHLY-10OFF` 只有九折。

按这个逻辑算一笔账：T1.TINY 月付 $6.90，年付标价 $76.90。套上七折循环码之后，年付落到大约 $54，折合每月 $4.5 上下。这不是"年付立减"，是"选对周期才有资格用码"。所以下单前先确认自己想要的套餐属于哪条线、哪档周期能被码覆盖，比直接比较月付年付数字更有用。

T1 的标价本身也能看出这一点：STARTER 月付 $12.90、年付 $154.80，MINI 月付 $21.90、年付 $262.80，两个数字分别正好是月付乘以 12，年付并没有自带折让。TINY 是个例外，$76.90 的年付比 $6.90 × 12 略低一点。换句话说，如果你的目标就是 T1 系列，年付的意义在于够到折扣码的门槛，而不是年付这个动作本身。

这说明年付的风险不是"钱打水漂"，而是"被迫换机器"。如果你的业务完全跑在单台日本 VPS 上，年付前想清楚迁移成本，比纠结那 30% 的折扣更重要。

## 年付之前必须先确认的三件事

**退款窗口比你想的窄。** DMIT 的规则是：新订单 3 天内、流量使用不超过 30GB，可申请全额退款；30 天内可按剩余价值部分退款，计算方式取剩余流量价值和剩余时间价值中较高的那一项。退款到账户余额不收手续费，退回原支付渠道会扣支付网关手续费，支付宝因为退款时返还手续费所以不额外收。已经续费的订单、用账户余额支付的发票、以及充值性质的订单不在退款范围内。年付金额大，务必在 3 天内把 IP、线路、延迟都测一遍。

**"线路不好"不构成退款理由。** 官方明确列出不予退款的情形包括：网络状况不佳、IP 地理位置限制、遭受 DDoS 攻击、同一产品线已退款满 3 次。这意味着 T1 这种不优化大陆方向的线路，你买到手发现国内访问慢，是设计要求，不是故障。

**续费价格要提前问清楚。** 循环折扣的码续费同价，一次性优惠的码续费回原价。这两者第一年的价格可能一样，第二年会差出一截。长期用的项目，优先找带 RECURRING 或循环字样的码。

## 什么样的人适合日本 VPS 年付

判断标准其实不复杂，看你的需求会不会在一年内变。

适合年付的情况：你明确需要日本原生 IP，业务面向日本或亚太用户；或者你要建的是长期跑的站、API 节点、中转落地；或者你预算敏感，愿意用一年的承诺换七折八折的循环价。T1.WEE 这种 $36.90 一年的机型，即使只是拿来测试线路，成本也不过分。

不适合年付的情况：你还没确定日本节点是不是最优解，需要先对比香港或洛杉矶的延迟；你的业务可能是临时性的，比如短期项目、活动期投放；以及你在意能否随时换配置——年付之后升级降级都比月付麻烦。这几种情况下，月付贵出来的那部分钱是你买的灵活度，不算浪费。

一个折中的做法是先月付买最低配的 Pro.TINY 或 T1.TINY 跑一到两周，确认延迟和稳定性符合预期，同系列再上年付。同一个产品系列退款次数有 3 次上限，别把测试额度用在反复试错上。
